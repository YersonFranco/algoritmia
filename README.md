# Algoritmia — Trayecto 1

Repositorio para organizar los ejercicios y aprendizajes del Trayecto 1 de Algoritmia. Los contenidos se irán agregando por semana y cada cambio se registrará en un commit.

## Página principal

Abre `index.html` en el navegador para ver las tarjetas de las semanas. La página usa Bootstrap 5.3 y los estilos propios de `css/style.css`.

## Temas del trayecto

1. **Semana 1:** introducción a los algoritmos y pensamiento computacional.
2. **Semana 2:** lógica proposicional y estructuras de decisión.
3. **Semana 3:** patrones de repetición y descomposición de problemas.

Los ejercicios, diagramas y páginas de cada semana se incorporarán en sus respectivas carpetas.
