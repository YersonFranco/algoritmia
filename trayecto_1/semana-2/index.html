Semana 2

Lógica proposicional y estructuras de decisión

Resumen: ¿qué aprendimos?

Aprendimos a convertir reglas escritas con palabras en condiciones que el algoritmo puede evaluar. Las condiciones permiten tomar decisiones y escoger qué instrucciones ejecutar.

  • Una proposición es una afirmación que puede ser verdadera o falsa; una pregunta o una orden no lo es.
  • Los operadores de comparación son >, <, >=, <=, igual y diferente.
  • Con Y deben cumplirse ambas condiciones; con O basta una; NO invierte el resultado.
  • Al negar una condición compuesta, se niega cada parte y se cambia Y por O (ley de De Morgan).
  • En PSeInt usamos decisiones simples y dobles con Si y SiNo, decisiones anidadas y alternativas con Segun.
  • Los casos borde se prueban antes, justo en y después del límite. La prueba de escritorio permite revisar los valores paso a paso.

Estas reglas lógicas también se pueden aplicar en formularios y otros programas. Los algoritmos de decisión de esta semana están escritos en PSeInt.

Orden lógico: primero NO, luego Y y al final O. Al mezclar operadores, los paréntesis hacen explícita la intención.

La trampa del paraguas: si llueve, Johan lleva paraguas. Si Johan llegó con paraguas, no se puede concluir que llovió: pudo usarlo por otra razón. La regla no afirma que solo lo lleve cuando llueve.

Formas de decisión: simple (Si), doble (Si / SiNo), anidada (una decisión dentro de otra) y múltiple (Segun).

JavaScript y formularios: en JavaScript se usan comparaciones estrictas como === y !==, decisiones con if/else y switch, decisiones anidadas, retorno temprano y operador ternario. También se utilizan const, valores truthy/falsy y cortocircuito. En HTML, required, min y max ayudan a validar campos.

Reto 2. Negar una condición sin equivocarse

Una edad válida está entre 0 y 120, inclusive: edad >= 0 Y edad <= 120. Para encontrar cuándo es inválida, aplicamos De Morgan: edad < 0 O edad > 120.

La negación correcta usa O: una edad es inválida si es menor que 0 o mayor que 120.

Ejercicios complementarios en JavaScript

Aplicamos proposiciones y decisiones a situaciones de calendario, acceso a eventos, descuentos, contraseñas e inventario.

Año bisiesto

Se aplica la regla de divisibilidad entre 4, 100 y 400; se incluyen los años borde 1900, 2000, 2024 y 2026.

function esAnioBisiesto(anio) {
  return (anio % 4 === 0 && anio % 100 !== 0) || anio % 400 === 0;
}

Acceso a un evento

Un adulto puede entrar con boleta; una persona menor puede entrar acompañada por un adulto con boleta. La tabla de verdad usa tres proposiciones.

function puedeEntrarAlEvento(edad, tieneBoleta, acompaniadoPorAdultoConBoleta) {
  const esAdulto = edad >= 18;
  return (esAdulto && tieneBoleta) || (!esAdulto && acompaniadoPorAdultoConBoleta);
}

Tarifa de un gimnasio

Estudiantes reciben 50 % de descuento y personas mayores de 60 años reciben 40 %. Si se cumplen ambas condiciones, se aplica el descuento mayor, no se suman.

function calcularTarifaGimnasio(tarifa, esEstudiante, edad) {
  let descuento = 0;

  if (esEstudiante) {
    descuento = 50;
  }

  if (edad > 60 && descuento < 40) {
    descuento = 40;
  }

  return tarifa - tarifa * descuento / 100;
}

Validador de contraseña

La contraseña debe tener al menos 8 caracteres, incluir un número y no contener la palabra password.

function validarContrasena(contrasena) {
  const tieneLongitudMinima = contrasena.length >= 8;
  const tieneUnNumero = /[0-9]/.test(contrasena);
  const contienePalabraProhibida = contrasena.toLowerCase().includes("password");

  return tieneLongitudMinima && tieneUnNumero && !contienePalabraProhibida;
}

Semáforo de inventario

Clasifica las cantidades negativas como error, cero como agotado, de 1 a 10 como bajo y más de 10 como disponible.

function estadoInventario(stock) {
  if (stock < 0) {
    return "Error";
  }

  if (stock === 0) {
    return "Agotado";
  }

  if (stock <= 10) {
    return "Bajo";
  }
  return "Disponible";
}
