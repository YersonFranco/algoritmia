Semana 3

Patrones de repetición y descomposición de problemas

Resumen: ¿qué aprendimos?

Aprendimos a repetir instrucciones con ciclos y a dividir un problema grande en partes pequeñas que podemos resolver y reutilizar. Para revisar que un ciclo funcione, hacemos una traza vuelta por vuelta.

  • Todo ciclo tiene inicio, condición, cuerpo y actualización. Si el dato de la condición nunca cambia, el ciclo puede quedar infinito.
  • Usamos Para cuando sabemos cuántas veces repetir; Mientras cuando repetimos hasta que ocurra algo; y Repetir ... Hasta Que cuando el cuerpo debe ejecutarse al menos una vez.
  • Los patrones de esta semana son contador, acumulador, bandera, máximo, mínimo, centinela y límite de intentos.
  • Los ciclos anidados permiten recorrer filas y elementos dentro de cada fila.
  • Un subproceso tiene un nombre, recibe datos y puede entregar un resultado. Descomponer y reutilizar partes ayuda a ordenar la solución.
  • El error por uno ocurre cuando un ciclo repite una vez de más o de menos; las trazas ayudan a encontrarlo.

Práctica complementaria: total de una compra

El programa suma los productos, aplica el cupón RIWI10, calcula el impuesto del 19 % y determina el costo del envío.

function calcularSubtotal(items) {
  let subtotal = 0;
  for (const item of items) {
    subtotal += item.precio * item.cantidad;
  }
  return subtotal;
}

function aplicarCupon(subtotal, codigo) {
  if (codigo === "RIWI10") {
    return subtotal * 0.9;
  }
  return subtotal;
}

function calcularImpuesto(valor) {
  return valor * 0.19;
}

function calcularEnvio(subtotal) {
  if (subtotal > 150000) {
    return 0;
  }
  return 8000;
}

function calcularTotal(items, codigoCupon) {
  const subtotal = calcularSubtotal(items);
  const totalConDescuento = aplicarCupon(subtotal, codigoCupon);
  const impuesto = calcularImpuesto(totalConDescuento);
  const envio = calcularEnvio(subtotal);
  return totalConDescuento + impuesto + envio;
}
